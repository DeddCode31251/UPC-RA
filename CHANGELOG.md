# Changelog

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - Initial Development Release

### Added
- Initial introduction of UPC-RA (Universal Product Code Rounded A-Format).
- Initial experimental barcode symbology concept.
- Concentric ring-based barcode structure.
- Radial sector organization for data representation.
- Three circular reference markers for orientation and alignment.
- Initial conceptual binary data representation.
- Initial project documentation.
- Repository security policy.
- Contribution guidelines.

### Documented
- Initial project architecture and design principles.
- Experimental nature and limitations of the symbology.
- Potential applications involving cylindrical product packaging.
- Initial considerations for barcode detection and decoding.

### Notes
- UPC-RA is an experimental barcode symbology.
- The technical specification is subject to change.
- No official GS1 recognition or standardization is claimed.
- Production readiness and comprehensive decoding reliability have not been established.

## Versioning Policy

UPC-RA follows Semantic Versioning:

`MAJOR.MINOR.PATCH`

- **MAJOR:** Introduces incompatible changes to the established specification or implementation interfaces.
- **MINOR:** Introduces backward-compatible functionality or specification extensions.
- **PATCH:** Introduces backward-compatible fixes and corrections.

During the experimental `0.x.x` development stage, breaking changes and significant structural modifications may occur between minor releases.

Version numbers refer to published project releases, not individual commits.
